ccp-observe

AI 编码代理观测面板 · 桌面端

本地代理暂未就绪，所以面板打不开。通常是这台机器上找不到 Python，或者端口被别的程序占用了。

1 · 确认已安装 Python 3

桌面端会自动寻找可用的 Python 3（依次尝试 CCP_PYTHON → py -3 → python → 常见安装目录）。如果你在终端里执行 python --version 看到「Python was not found」，那是 Windows 自带的商店占位程序，不算是安装——用 py -3 --version 试试。

py -3 --version

如果没有，请安装 Python 3.9+。也可以设置环境变量 CCP_PYTHON 指向解释器绝对路径：

setx CCP_PYTHON "C:\Users\you\AppData\Local\Programs\Python\Python313\python.exe"

2 · 检查端口

8787 被占用时代理会自动往后顺延（最多 20 个端口），所以端口冲突通常不会导致失败； 但如果连顺延的端口都被占满，或者别的程序在应答 /healthz，就会卡在这里。

# Windows
netstat -ano | findstr :8787

3 · 直接手动启动（排查用）

py -3 proxy/proxy.py --port 8787

看到 CCP_READY 后，在浏览器打开 http://127.0.0.1:8787/_ccp/ 即可。 如果它换个端口启动，以 CCP_READY 那一行里的地址为准。

修好后重新打开桌面端，或点击托盘图标「打开面板」重试。日志在 %APPDATA%\ccp-observe\desktop.log。
